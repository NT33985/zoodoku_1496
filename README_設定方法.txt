ZooDoku!! を GitHub Pages で公開する方法

1. ZIPファイルを解凍します。
2. index.html, manifest.webmanifest, sw.js と PNG画像ファイルを、GitHubのリポジトリの一番上（同じフォルダ）にアップロードしてください。
3. GitHub Pagesで公開しているURLをスマホのブラウザで開きます。
4. iPhone: Safariの「共有」→「ホーム画面に追加」。Android: Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」。
5. 前のホーム画面アイコンが残っている場合は、古いショートカットを削除してから追加し直してください。

ゲーム記録は、同じURL・同じブラウザのストレージを使う限り引き継がれます。
